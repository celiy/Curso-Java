Versões do Java (LTS): 8, 11, 17, 21, 25

Java 8 (março de 2014)
- Lambdas, Streams API, métodos default, Optional e java.time.
- Caso de uso: sistemas legados e corporativos que ainda rodam nele; há muito código e bibliotecas existentes.
- Por que alguém usa: já está em produção e migrar custa caro.

Java 11 (setembro de 2018)
- Primeiro LTS depois do Java 8. Traz var, o HTTP Client padrão, novos métodos de String (isBlank, lines, strip, repeat) e a execução direta de código-fonte de um arquivo com "java Arquivo.java".
- Caso de uso: passo comum de atualização a partir do Java 8, com amplo suporte de bibliotecas.
- Por que alguém usa: alvo estável e conservador ao sair do Java 8.

Java 17 (setembro de 2021)
- LTS. Traz records, sealed classes, text blocks, pattern matching para instanceof e switch expressions.
- Caso de uso: padrão para projetos novos e frameworks (por exemplo, o Spring Boot 3 exige Java 17 ou superior).
- Por que alguém usa: sintaxe moderna com um ecossistema maduro.

Java 21 (setembro de 2023)
- LTS. Traz virtual threads (threads leves para alta concorrência), pattern matching para switch, record patterns e sequenced collections.
- Caso de uso: servidores e serviços que atendem muitas requisições simultâneas, como microsserviços.
- Por que alguém usa: código concorrente bem mais simples, sem precisar de frameworks reativos.

Java 25 (setembro de 2025)
- LTS mais recente. Finaliza construtores mais flexíveis, compact source files e instance main methods (programas mais simples para iniciantes), module import declarations e Scoped Values. Structured Concurrency ainda está em preview. Remove o port de 32 bits para x86.
- Caso de uso: projetos novos que querem o LTS mais recente e as melhorias mais recentes da linguagem.
- Por que alguém usa: é a versão LTS com suporte mais longo, com suporte previsto até a década de 2030.

Diferenças em resumo
- Java 8 -> 11: atualizações de bibliotecas e ferramentas; o primeiro passo para sair do Java 8.
- Java 11 -> 17: grande avanço na sintaxe da linguagem (records, sealed classes, text blocks, pattern matching).
- Java 17 -> 21: concorrência (virtual threads) e mais pattern matching.
- Java 21 -> 25: estrutura de programa mais simples para iniciantes e limpeza da linguagem; alguns recursos ainda estão sendo finalizados.
- Todas são versões LTS, então recebem atualizações de longo prazo dos fornecedores. Versões não LTS (como 22, 23 e 24) recebem atualizações por apenas cerca de seis meses.
